# C Programming Projects

한동대학교 C프로그래밍 수업에서 수행한 프로젝트를 정리한 저장소입니다.

## Dormitory Management System
구조체와 파일 입출력을 활용하여 생활관생의 정보를 관리하는 프로그램입니다.

주요 기능
- 생활관생 목록 조회
- 호실 변경
- 벌점 부여
- 학생 검색
- 생활관 현황 보고서 저장

## Hotel Reservation System
객실 정보를 관리하고 예약 및 예약 취소 기능을 수행하는 프로그램입니다.

주요 기능
- 객실 목록 조회
- 객실 예약 및 예약 취소
- 예약자 검색
- 조건에 맞는 빈 객실 검색
- 신규 객실 추가
- 객실 현황 보고서 저장

## Language
- C

## Concepts
- Structure
- Pointer
- Dynamic Memory Allocation
- File I/O
- String Handling
